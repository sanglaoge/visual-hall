# 视觉厅 v3 · 设计审计

> 审计对象：`/Users/sanglaoge/valve/视觉厅-优化`（分支 `wip/2026-11-07-v3`，预览 `127.0.0.1:4501`）
> 审计方式：静态 HTML/CSS/JS 逐行阅读 + 本地 headless Chrome 截图（1440 明暗、390 手机、品牌页/品牌墙/辅料页）
> 审计范围：首页 `index.html`、`brand.html?b=gogreen`、`library.html`、`accessories.html`、`assets/gallery.css`、`assets/scrollcraft.css`、`index.html` 内联样式与脚本
> 本报告只读审计，未修改任何站点文件。

## Design Read

Reading this as: 个人跨境电商视觉作品集，给领导看，品牌优先、作品说话，安静的电影感/编辑部档案；倾向 自定义 CSS + scroll-craft 滚动骨架 + 编辑部索引 + 纸样台材质，动效克制，不走向广告公司炫技。

三旋钮建议：

- `DESIGN_VARIANCE: 8`（保留编辑部索引和纸样台的强构图）
- `MOTION_INTENSITY: 5`（项目文档写的是 7，但 brief 的“安静”要求 5 以下）
- `VISUAL_DENSITY: 4`

当前实现更像 `9 / 8 / 5`：动效不是不够，是太抢。问题不在“有没有动效”，在“动效有没有让作品更清楚”。

## 一句话判断

方向是对的：品牌索引和纸样台已经让这个站有了“编辑部档案”的骨架；但首屏和章节标题被滚动装置抢了戏，品牌页又换了一套字体和语气，手机端还有真实的压字、断行和裁切。现在是可以内部评审的 v3 草稿，还不是能直接递给领导的成品。

## P0：先修，影响第一眼和可信度

### P0-1 首屏卡片压字，手机最严重

- 页面：`index.html` `#hero`，`.orbit`（z-index 1）与 `.hero-center`（z-index 30）
- 证据：`.hero-center` 的背景是 `radial-gradient(... var(--sc-canvas) 60%, ... transparent 80%)`（第 203-217 行）。卡片没有被排除在中心安全区外，明暗两版都能从 `VISUAL` 字缝、`这一年的活`、两个 CTA 后面透出；390 截图里白色毛巾堆叠直接压在标题后，Kingrest 礼盒压在“看作品”按钮后。
- 改法：
  1. 在 JS `place()` 里加中心安全区：`var rMin = 0.34 * Math.min(W, H); if (r < rMin) r = rMin;`，让卡片不在中心生成；手机 `CARD_N` 从 14 降到 10。
  2. 快速兜底：给 `.orbit` 加中心镂空 `mask-image: radial-gradient(ellipse 48% 44% at 50% 52%, transparent 0 58%, #000 82%)`。
  3. 把 `.hero-center` 的中心底色从 60% 提到 88%（暗色 94%），只保留软边，不要整块实心面板。
  4. 首屏图库做一次角色筛选：只留生活场景/氛围图，白底 cutout 移到产品区。
- 验收：390 和 1440、明暗两版，标题、正文、两个按钮后面 0 张卡片。

### P0-2 章节跳转把标题藏在 48px 吸顶栏下

- 页面：`index.html` 所有 `data-goto`、`.rail-word`、浏览器 hash
- 证据：`.site-head` 高 48px（第 50 行）；`scrollToEl()` 只做 `lenis.scrollTo(el, { offset: 0 })` 或 `el.scrollIntoView()`（第 819-822 行）；没有任何 `scroll-margin-top`。手机截图 `m-home-craft`、`m-home-film` 顶部标题都被切掉一半。
- 改法：
  ```css
  section[id] { scroll-margin-top: 64px; }
  @media (max-width: 899px) { section[id] { scroll-margin-top: 56px; } }
  html { scroll-padding-top: 64px; }
  ```
  Lenis 的 `offset` 语义容易搞反，优先用 CSS `scroll-margin` + 原生 `scrollIntoView`，少一层手写偏移。
- 验收：点四个 tab、四个 rail word、以及直接打开 `#craft`，标题都完整出现在吸顶栏下方。

### P0-3 手机产品名断行

- 页面：`index.html` `#collection`，`.cell .lab`
- 证据：390 截图第一张卡标题变成“电热 / 毯”。`.cell .lab` 是 `display:flex; justify-content:space-between`，`b` 没有 `white-space:nowrap`，右侧“5 套 · 深蓝 / 卡其 / 灰 / 粉 / 白”太长，把标题挤断。
- 改法：
  ```css
  @media (max-width: 600px) {
    .cell .lab { flex-direction: column; align-items: flex-start; gap: 4px; }
    .cell .lab b { white-space: nowrap; }
    .cell .lab > span { text-align: left; }
  }
  ```
  同时把颜色列表缩成“5 套 · 5 色”，完整色名放详情页。
- 验收：390 截图，所有产品名一行；最长“单面橡筋兔毛毯”也不断。

### P0-4 品牌墙白字压亮图，对比度不足

- 页面：`library.html` `.bcard`，`.veil` / `.yr` / `.cats` / `.go`
- 证据：浅色和深色两版，GOGREEN 顶部“2025 · 品牌线”几乎看不见；KINGREST / 2026 卡的“进入 →”在白色床品上消失；底部品类行在浅色图上低于 4.5:1。`.veil` 从 18% 才开始透明，`.yr` 是 `rgba(244,241,234,.62)`，`.cats` 是 `.55`。
- 改法（优先 A）：
  - A. 把文字移出图片：`.bcard` 改成图片 + 下方实色信息条，`background: var(--ink); color: var(--paper); padding: 18px 20px;`，`.veil` 删掉。这样品牌名、年份、品类、进入都在实色上，最稳。
  - B. 保留压图：`.veil` 改成 `linear-gradient(180deg, rgba(10,10,12,.55) 0%, rgba(10,10,12,.15) 30%, rgba(10,10,12,.92) 100%)`，`.yr/.cats/.go` 全部提到 `.9` 以上，`.go` 加实色底。
- 验收：用 DevTools 取色，正文 ≥4.5:1，大标题 ≥3:1；在最亮的 GOGREEN 圣诞图和 KINGREST 白床图上都能读。

### P0-5 2026 新品封面是 KINGREST 礼盒

- 页面：`index.html` `#brands` 第 4 行 `assets/orbit-card/m011.webp`；`library.html` 2026 卡使用 `WORKS.brands.own.cover`，即 `assets/main/m001/01.webp`
- 证据：两处都是带 Kingrest 皇冠 logo 的礼盒。领导会把“2026 新品”读成 Kingrest 的子系列，品牌优先的叙事当场断掉。`library.html` 还把 2026 和新品并列成“4 个品牌 / 年份”，等于承认这个分类是混的。
- 改法：
  1. 换一张不带其他品牌 logo 的 2026 封面（纯产品/场景）。
  2. 如果 2026 确实是 Kingrest 生产，图上明确写“2026 新品 · Kingrest 生产”，并把入口从“第 4 个品牌”改成“2026 系列”独立入口。
  3. `library.html` 的 `bCount` 改成“3 个品牌 + 2026 新品”，不要写“4 个品牌 / 年份”。
- 验收：找一个不了解项目的人看首屏和品牌墙，问“2026 新品是谁的”，答案不应是 Kingrest。

## P1：结构 / 体验，影响“像不像成品”

### P1-1 巨字 word rail 和章节标题打架，还压住链接

- 页面：`index.html` `.wordrail` / `.rail-word`，JS `activeVars()` 第 1112 行
- 证据：active 状态 `top: 92px; right: 16px; font-size: clamp(2.2rem,4vw,3.5rem)`，z-index 35。`d-home-brands` 里 `BRANDS` 和“先看品牌”同屏；`d-home-craft` 里 `CRAFT` 直接压住纸样台右上角“全部辅料 →”；`d-home-film` 里 `FILMS` 压住“AI 生成 · 9:16 · 循环静音”，上方还留着 22% 的 `CRAFT` 残影。右侧同时有巨字、meta 条、ruler 数字、进度百分比。
- 改法：
  1. 首选：删掉 `.wordrail`，让中文 h2 承担章节标题，ruler 保留为唯一固定装饰。
  2. 如果保留：把巨字缩到 12-14px 的竖排索引，active 时移到章节标题旁做小标签；不要 3.5rem。
  3. 给桌面 `.wrap` 加 `padding-right: 120px` 的右侧安全带，至少保证巨字不压内容；`.rail-word` 只保留小块点击区，不要整块 `pointer-events:auto`。
  4. `CRAFT` 这个词也不对：这一节是包装/辅料/印刷稿，英文应该用 `PACKAGING` 或 `PRINT`，不是 `CRAFT`。
- 验收：任意滚动位置，巨字不覆盖 h2、meta 条、lab-row、desk-head 链接；一节只有一个主标题。

### P1-2 品牌入口缺 logo、缺数量，品牌名出现三种写法

- 页面：`index.html` `.brow` / `.bname`；`library.html` `.bcard h2`；`brand.html` `.b-head h1`
- 证据：`assets/brand-logos/` 里已有 `gogreen-horizontal.png`、`Hitime-primary.png`、`Kingrest-dark.png`，但只在 `prototypes/brand-gate/` 里用过，线上三个页面都没用。GOGREEN 在首页是 Archivo 700 大写字，在品牌页是 Songti 76px，在品牌墙是 Songti 44px，在包装上是绿色 logo，四种身份。
- 改法：
  1. 做一个统一的 brand mark 组件：logo 图高度 20-24px，明暗两套，名称作为 `alt` 和 fallback。
  2. 首页品牌行补“规模”：右侧加一列 `78 套 / 685 张 / 35 份辅料`，或把套数做成大数字。领导第一眼要看到“这个品牌做了多少”，不是只有品类名。
  3. 品牌页 h1 上方放同一枚 logo，名称退到副标题。
- 验收：GOGREEN 在首页、品牌墙、品牌页看起来是同一个 GOGREEN。

### P1-3 品牌页首屏有 280px 空洞，且换了一套字体语言

- 页面：`brand.html` `.b-head` 第 12-23 行
- 证据：`.b-head { align-items:end; }`，左侧标题块比右侧 4:3 封面矮，底部对齐后标题被推到封面下沿，`d-brand-top` 里从 back link 到 GOGREEN 之间空了约 280px。品牌页用 Songti + PingFang，首页用 Archivo + Geist Mono + Instrument Serif；同一个“视觉厅”在两边字重和字距都不同。
- 改法：
  1. `align-items: center` 或 `start`，把顶部 padding 收到 `clamp(20px,4vh,40px)`；back link 可以移到 topbar，不要单独占一行。
  2. 决定一套字体：要么品牌页也加载 Archivo/Instrument Serif 的子集，要么全站统一到“首页 Archivo + 品牌页 Songti”的双轨规则，并在文档里写清楚。
  3. 品牌页 h1 改用 logo，Songti 只做品类/说明。
- 验收：1440 首屏同时看到 logo、一句上下文、封面、筛选；没有 280px 空白。

### P1-4 品牌页 35 份辅料埋在 78 套之后

- 页面：`brand.html` 第 155-176 行
- 证据：先渲染筛选和 `#sets`，再 `if (acc.length)` 追加辅料。GOGREEN 78 套 / 685 张，手机页长约 25k-30k px，35 份辅料在页面最底部；但头部 stats 写着“35 份辅料”，领导点进来却看不到。
- 改法：
  1. 头部 stats 的“35 份辅料”做成 jump link，点击滚到辅料区。
  2. 或加“套图 / 辅料”两个 tab，切换主网格。
  3. 或把辅料块移到筛选下方、套图之前，作为品牌的第二个入口。
- 验收：从品牌页顶部一次点击到辅料，不需要滚 25k px。

### P1-5 品牌页短标题过度压缩，露出 SKU 和内部备注

- 页面：`brand.html` `shortTitle()` 第 204-210 行、`subTitle()` 第 211-220 行、`filter-note` 第 162 行
- 证据：`shortTitle()` 把“圣诞款四件套（01-圣诞老人头）”压成“圣诞款四件套”，连续 5 张卡都叫“四件套”；`subTitle()` 退化成“02-G018SS2501CK-桃花木”，CSS 再 ellipsis 成“01-G018SS2501CK…”。筛选里有“床笠 0”；`3 套暂不展示（功能图或全部标记不要）` 是工作台内部话术，不该给领导看。
- 改法：
  1. 标题用“可区分的花型/款式”：“圣诞老人头四件套”“白雪花四件套”“麋鹿头四件套”；SKU 只放 lightbox 标题或 `title` 属性。
  2. 隐藏 count 为 0 的 chip，或置灰并标“暂无”。
  3. 内部备注改成“部分套图为功能图，暂未收录”，或直接删掉。
- 验收：连续 10 张卡有 10 个可读、可区分的名字；页面上没有 SKU 长串和内部工作流语言。

### P1-6 视频章：三支品牌片同时自动播，产品片小到读不清卖点

- 页面：`index.html` `#film`，`.reel.brand` 的 `<video data-auto>` 第 729-746 行；IntersectionObserver 第 1177-1185 行；`.reel.land` 第 751-782 行
- 证据：三支 9:16 品牌片都在视口 45% 时自动播放，桌面三支同时循环；产品片是 16:9，却和品牌片共用三等分网格，在 1440 下每支约 300px 宽，片子里的 “Cold nights?” 文案已经很小，卖点分镜更看不清。
- 改法：
  1. 只让“主片”自动播，另两支留 poster，hover/click 再播；同一时间最多一支在动。
  2. 产品片改成 2-up，或“1 大 + 2 小”：大的是 16:9 主卖点片，小的做 poster 索引；不要和三支竖版共用 3 列。
  3. 去掉 `frame-no` 的 01/02/03 药丸，标题已经在 figcaption 里。
- 验收：1440 下产品片里的主文案不放大也能读；同一屏最多一支视频在播放。

### P1-7 手机端没有章节导航，ruler 压在图片上

- 页面：`index.html` `@media (max-width:899px) { .tabs { display:none; } }` 第 95 行；`.ruler` 第 100-124 行；`.hud-row` 第 251-256 行
- 证据：手机顶栏只剩“全部作品”和主题按钮，页面 9776px 没有章节跳转；ruler 的 tick 和 pct 仍在，390 截图里压在品牌缩略图、产品卡、视频卡右边缘；HUD 行“实拍 + AI 生图 / 2026 / GOGREEN / HITIME / KINGREST”在 390 下断成两行，最后一项被挤到下一行。
- 改法：
  1. 手机保留一条横向章节 chip：品牌 / 产品 / 辅料 / 视频，`overflow-x:auto; scroll-snap`，高度 44px，放在 header 下方。
  2. `@media (max-width:900px){ .ruler{display:none} }`，手机上不需要百分比刻度。
  3. 删掉 `.hud-row`，它是首屏底部的装饰文字条，信息与品牌门重复，且是模板 tell。
- 验收：390 下不用滚到底就能跳到四章；固定 chrome 不覆盖任何图片；首屏没有断行的小字条。

### P1-8 每个章节有三套标题系统

- 页面：`index.html` `.sec-title` + `.meta-strip` + `.wordrail`；品牌门 `.brow .no`；产品网格 `.gcell` 的 01/02/03
- 证据：一节里同时出现：中文 h2（“先看品牌，再看作品。”）、英文巨字（BRANDS）、编号 meta 条（01 / 品牌）、行号（01-04）。产品区又有“新品系列 01 / 节日系列 02 / 全部作品 03”。编号在三个层级上重复，但含义不同。
- 改法：
  1. 一节只留一个主标题；英文巨字要么替代 h2，要么降为 10-11px 的 eyebrow。
  2. 编号只保留一层：要么章节编号，要么行号，不要两套。
  3. `meta-strip` 只放真实信息（年份、数量、材质），不要放“01 / 品牌”这种为了排版而存在的编号。
- 验收：截任意一屏，第一眼只有一个标题起点。

### P1-9 首屏主 CTA 跳过品牌门

- 页面：`index.html` 第 574 行 `<button ... data-goto="collection">看作品</button>`
- 证据：首屏下方第一个章节是 `#brands`（“先看品牌，再看作品”），但主 CTA 直接跳到 `#collection`，把品牌门跳过去。故事说品牌优先，按钮说产品优先。
- 改法：主 CTA 改成 `data-goto="brands"`，文案“先看品牌”或“开始看”；次 CTA“看片子”保留。这样第一跳和 h2 的主张一致。
- 验收：点主 CTA，落点是品牌门，不是产品网格。

### P1-10 “按产品浏览”链接到品牌墙

- 页面：`index.html` 第 660 行
- 证据：`<a class="more-bar" href="library.html"><span>全部作品 · 按产品浏览</span>`，但 `library.html` 是品牌墙（GOGREEN / HITIME / KINGREST / 2026），不是产品索引。

### P1-11 “买家秀”是 AI 场景合成，名称要先说清楚

### P1-12 交互与稳健性：hero 卡片、灯箱、自动轮播、跨平台字体

- 页面：`index.html` `.oc { cursor: zoom-in }` 第 192 行 + click 只做 boost 第 994-1001 行；`gallery.js` 灯箱第 4-34 行、主题按钮第 111-127 行；`brand.html` 第 190-199 行；`library.html` 第 193-207 行
- 证据：
  - hero 卡片是 `zoom-in` 光标，点击却只是把卡片放大 3 倍，不打开大图，和光标承诺不一致。
  - 灯箱是 `div`，没有 `role="dialog"`、`aria-modal`、焦点陷阱、关闭后焦点返回。
  - 品牌页封面 5 秒自动轮播，品牌墙 6 秒自动轮播，没有暂停按钮；WCAG 2.2.2 要求可暂停。
  - `brand.html` / `library.html` / `accessories.html` 依赖 JS 渲染，禁用 JS 或脚本报错就是空白页，没有 `<noscript>` 兜底。
  - 品牌页/品牌墙字体是 `Songti SC` + `PingFang SC`，Windows 上没有这些字体会掉到宋体/黑体，和 Mac 上差别很大。
- 改法：
  1. hero 卡片点击打开 lightbox（复用 `gallery.js` 的 `window.Lightbox`），或把光标改成 `pointer` 并去掉“放大”暗示。
  2. 灯箱补 `role="dialog" aria-modal="true"`、打开时 focus 到关闭键、Tab 循环、关闭后 focus 回触发卡。
  3. 自动轮播加暂停按钮，或改成手动 dots；品牌页封面建议直接静态。
  4. 三个 gallery 页加 `<noscript>` 提示或首屏静态内容。
  5. 字体：给 gallery 页加一套自托管/子集的 CJK 衬线（只取标题用到的字），或统一用系统可用的 `Noto Serif SC` webfont；不要只依赖 macOS 字体。
- 验收：键盘能完整走完灯箱；Windows 截图和 Mac 截图品牌页标题不塌；JS 关闭时页面至少有一句说明。

## P2：细节，影响“精致度”

### P2-1 编号和药丸太多

### P2-2 2026 深色行在暗色主题里消失，且左对齐被 padding 推歪

- 位置：`index.html` `.brow.own` 第 332 行
- 证据：`.brow.own { background:#171512; padding-inline:22px; }`，在暗色 `#0e1219` 上几乎和背景融为一体；同时 22px 的 inline padding 让 2026 行的编号和品牌名比其他行右移 22px。

### P2-3 纸样台说明文字太小太淡，大图白上白

- 位置：`index.html` `.pd-card figcaption` 第 391-395 行、`.pd-card .paper` 第 384-390 行

### P2-4 产品网格第一张是礼盒，不是产品

### P2-5 结尾太空，文案和日期要收

## 首页剩余三章的建议结构

三章不要做成三排一样的卡片。建议三种不同的版式家族：视频=放映室，买家秀=接触印相/样片墙，流程=生产线。这样也满足“同一版式家族最多出现一次”的规则。

### 一、视频章（重做 `#film`）

**放什么**

- 1 支主片：品牌片里选一支最有电影感的 9:16（建议 `v03 从村落回到卧室`），大画面、poster 先出。
- 7 条索引：其余 7 条做成右侧片单，每条一行：16:10 缩略图 + 标题 + 格式（竖/横）+ 时长。
- 1 组“同片两版”：同一产品的 16:9 上架版 + 9:16 投流版并排（例如电热毯 `v05` + `v04`），这是最能说明“会做多平台”的一组。
- 1 行说明：`8 条 · 竖版 5 / 横版 3 · AI 生成 + 代码生成`。

**怎么排**

- 桌面 12 列：左 7 列主片（9:16，最大 560px 宽，居中留白），右 5 列片单；片单每行 72-88px 高，hover 才出预览。
- 下方“同片两版”用 2 列：16:9 和 9:16 各一，宽度不等，高度对齐；不要三等分。
- 手机：主片全宽 9:16；片单改成横向 scroll-snap 的 9:16 poster 条；“同片两版”上下叠。

**图片角色**

- poster 是主视觉，视频是奖励；主片 muted 循环，其余 poster 静止。
- 缩略图只做“索引”，不承担卖点阅读；产品片的 16:9 主文案要大到不放大也能读。
- 不再用 01/02/03 药丸压在 poster 上。

**动效**

- 同一时间最多 1 支在播；主片进入视口才播，离开暂停。
- 片单 hover 预览 1.5 秒，移出恢复 poster；点击才带声音播放。
- reduced-motion：全部 poster + 手动播放。

### 二、买家秀章（新增，位置放在视频之后）

**放什么**

- 1 张 2×2 大场景（沙发/床铺/宠物，选最有生活感的一张）。
- 8-12 张 4:5 场景图，按产品分组：电热毯 / 兔毛毯 / 绗缝被 / 法拉绒 / 面料特写。
- 3-4 张面料微距：绒毛、绗缝线、印花边缘，1:1 或 4:5，满幅裁切。
- 1 行说明：`场景合成 / 非真实买家上传`（如果继续叫“买家秀”，这行必须放第一屏，不要只放页脚）。

**怎么排**

- 接触印相式：3 列，不做等宽等高的卡片；左上放 2×2 大图，其余 4:5 小图围绕；行与行之间只留 8-12px，像样片墙，不像电商列表。
- 面料微距单独一条横向 scroll-snap 带，宽度 220-260px，满幅、无白边。
- 手机：2 列，2×2 大图全宽，微距条横向滑动。

**图片角色**

- 场景图负责“用起来是什么感觉”，微距负责“面料是什么质感”；不出现白底 packshot。
- 统一暖调，和品牌片的色调一致；不要在同一屏混入冷白棚拍。
- 人物出现时只做氛围，不做“买家头像”式特写，避免假 UGC 感。

**动效**

- 这章不需要自动播放；点击开灯箱，左右翻。最多加一个进入视口的 8px 淡入，不要跑马灯。

### 三、制作流程章（新增，放在买家秀之后、结尾之前）

**放什么**

- 6 个工位：选品 → 定稿 → 做辅料 → 大货 → 拍摄 → 成稿。每站一个动词短语，不要“Step 01/02/03”。
- 每站标角色：运营 / 公司设计 + 工厂 / 我 / 工厂 / 我 / 我 + 摄影公司。领导最想知道“哪些是你做的”。
- 1 组 before/after：左边手机实拍原图，右边 AI 成稿，同一产品、同一角度；标题“同一张实物，左边手机实拍，右边成稿”。
- 1 张桌面大图：纸样、手机、屏幕、色卡同框，作为这一章的“工作台”主视觉。
- 1 行工具：手机 / Lovart nano banana / GPT Image 2 / Photoshop（只写真实用到的）。

**怎么排**

- 桌面：6 列横向生产线，一条 hairline 贯穿；每列上面 3:2 或 4:5 图，下面 2 行字（工位名 + 角色）。6 列在 1440 下每列约 190px，图不要太小；可以做成 2 行 × 3 列，避免 6 列太挤。
- before/after 单独一行，左右各 50%，中间一条细线；不要做自动滑块，静态对照更可信。
- 手机：竖排 6 行，图 40% + 文字 60%；如果太长，合并成 3 个大段（选品/定稿、做辅料/大货、拍摄/成稿），但每段里仍写清 6 个动作。
- 这一章吸收现在的 `.method` 三条，不再单独保留方法条。

**图片角色**

- 流程照片是“证据”，不是“作品”：3:2 或 4:5、统一轻度去饱和、带一句说明；不要用精修主图冒充车间照。
- 没有真实车间/打样照片时，用现有辅料/包装/手机实拍素材，但图上标“示意”，不要编。
- before/after 是整章的核心，必须同一产品、同一角度；这比任何“6 步图标”都有说服力。

**动效**

- 桌面可以做一条 scroll-linked 的横向生产线，但不要 pin 太久；手机不做横向滚动，直接竖排。
- 每站进入视口淡入 8px，stagger 60ms；reduced-motion 直接显示。

### 建议的首页顺序

1. 首屏：一句话 + 一张主视觉（不要 28 张卡片同时抢）
2. 品牌门：3 个品牌 + 2026 系列，带 logo、套数、图片数、辅料数
3. 2026 精选：8 个产品，第一张必须是产品，不是礼盒
4. 包装/纸样台：保留，修说明文字和 CRAFT 压链接
5. 视频：放映室结构
6. 买家秀/场景：接触印相
7. 制作流程：生产线 + before/after
8. 结尾：一句 + 全部作品
