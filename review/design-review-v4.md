## 四个 skill 各自会说什么

### design-taste-frontend

- **成立**：设计读是「设计师作品集 / 编辑部档案 / 牛皮纸印刷台」，不是通用 SaaS；六段版式不重复，图像是真实产物。
- **会扣分**：Instrument Serif 斜体是它点名的 AI 编辑风；米白 + 牛皮纸 + 近黑是它点名的 warm-craft 默认；产品章 8 张两列已收短。
- **判断**：衬线和暖纸是这套站的材质理由（包装稿、牛皮纸、纸样台），不是无脑默认；保留。

### hallmark

- **硬规则会 FAIL**：一个罗马标题里塞一个斜体词、每段 tracked 大写标签、middle dot 串、箭头粘在链接上、装饰圆点。
- **判断**：这些是站点的编辑语言，不是生成式偷懒；Hallmark 是新建站的标准，不拿来把现有系统磨平。
- **真正该学的**：一屏一个想法、英雄首屏可见、材质真实——这三点站里已经做到。

### impeccable

- **技术分 15/20**：牛皮纸文字对比度、PLAY 可读性、手机触点、流程横滑、图片管线都已修。
- **还剩**：全页 6.5MB、刻度尺百分比 3.29:1、暗色 HUD 偏暗（装饰信息）、orbit 目录 78MB 只有 36 个被引用。

### scroll-craft

- **成立**：7 个设备家族（orbit / 品牌索引 / 产品网格 / 纸样台 / 影片带 / 场景拼贴 / 流程网格），没有连续两次同一设备；有签名动作（orbit + wordrail）；结尾收得住。
- **会扣分**：`01 / 06` 段落计数器（本轮已去掉）；全页约 14 个视口高度，在上限；产品章是唯一一段「长度大于信息」的地方。

## 本轮改了什么

1. **去掉六段 `01–06` 计数器**，meta 条改成左右两条真信息（如「2025 品牌线 / 2026 新品」），减少模板节奏。
2. **英雄层级**：桌面 h1 25.6 → 32px，wordmark 72 → 65.6px；首屏先读消息，再读 logo。
3. **手机隐藏 HUD 行**：原来 CSS 顺序写反，390 下 HUD 一直显示并压到 orbit 卡片上。
4. **产品章收短**：去掉「兔毛毯 · 雾蓝」和「毛巾」，按电热毯 → 兔毛毯 → 绗缝被 → 水洗磨毛布 → 万圣毯 → 圣诞毯 → 圣诞床单 → 圣诞被套重排；圣诞被套换成 GTHS 被套套件（原 H018 是床单）。
5. **手机产品章改 2 列**：标题只留品类名，颜色/套数收起；页高 13.8k → 11.5k。
6. **首屏幽灵卡片放大改清晰图**：点击不再用发虚的 1600 orbit 图，改用主图 1200 原图，并在 hover 时预加载。
7. **仓库瘦身**：删除 146 个未引用文件（79 个 orbit 旧图、47 个 orbit-card、21 个旧辅料图），工作树减 27.8MB；不碰还在用的 133 张 a25 cover。

## 没改、也不建议现在改

- Instrument Serif 斜体尾：它是全站编辑语气的一部分，换掉是重做识别，不是优化。
- 米白 + 牛皮纸：材质来自包装稿，不是通用暖米色。
- 产品章保留两列大图：8 张是当前平衡点；再短就要上「3 列 / 横滑」，会牺牲图的大小。
- 视频竖版 6 条：现在按画幅分组，6 条是完整片单；放大要牺牲同屏数量。
